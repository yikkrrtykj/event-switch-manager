## Evidence and delivery

- Report unit, config fixture, Console simulation, service integration, OS end-to-end and hardware evidence separately. Each result records the revision, environment and reproducible evidence.
- Core migration tests must cover both default routes to Hillstone and return paths to the Core and VPN, including failure of the primary ISP and Tunnel. DHCP acceptance captures client-to-relay-to-Kea behavior and verifies options and reservations.
- Each PR has CI results and a short PASS / FAIL / SKIP / BLOCKED summary. Missing hardware evidence is NOT VERIFIED. Fix failed CI before review. Use ordinary merge only after authorization, then verify the main SHA. No rebase.
